# Abduction — inference to the best explanation

Objective: generate the most plausible hypothesis for surprising, incomplete, or
anomalous data — then hold it at the right epistemic distance.

## Where abduction sits

- **Deduction**: Rule + Case → Result. Proves.
- **Induction**: Case + Result → Rule. Generalizes.
- **Abduction**: Result + Rule → Case. *Explains.*

Abduction is the only one that generates new ideas, and the only one whose output is
provisional by construction.

## Entry condition

Check first: is the observation actually anomalous — does it defy current
expectations? If existing rules already explain it, use deduction and stop. Abducing
an explanation for something already explained is wasted motion and invites novelty
bias.

## The generator

For each candidate cause in the space of possibilities, apply the fundamental
abductive test:

> If this cause were true, would the observation follow as a matter of course?

If the observation would still be surprising given the cause, the cause isn't an
explanation of it. Keep only candidates that pass.

Generate several. A lone hypothesis is a conviction with better branding. Include at
least one candidate that would be inconvenient or embarrassing if true — motivated
reasoning skips exactly those, which is why they're disproportionately often correct.

## The forensic filter — ranking

Sort by explanatory economy, not by which one feels most likely.

**Minimality (Ockham).** Every new, unobserved entity a hypothesis requires is a heavy
cost. Count the leaps of faith explicitly. A story requiring three unverified things
to be simultaneously true is expensive even when each is individually plausible.

**Coherence check.** Does the hypothesis contradict something already established? If
so, refute and drop it — don't merely discount it. Contradiction is disqualifying, not
a deduction of points.

**Explanatory depth.** Does it account for the *entire* anomaly, or one symptom of it?
A cause that explains the magnitude but not the timing, or the timing but not the
scope, is incomplete — and partial coverage is a strong signal that something else is
doing the real work.

## Calibration — preventing overreach

Abduction does not prove truth. It justifies adopting a hypothesis for further
testing. The output must carry that distinction in its language.

Eradicate deductive certainty: "this proves", "the cause is", "clearly what happened".
Use the mechanics of explanation instead:

> Given the surprising observation, the most coherent explanation requiring the fewest
> assumptions is [cause]. If true, this mechanically accounts for the anomaly. What
> would confirm or kill it: [specific check].

The named next test matters. A hypothesis with no proposed way to falsify it hasn't
been reasoned about, it's been chosen.

## The trigger

Incomplete data, a mystery, a diagnostic failure, or a "why" question about something
anomalous. Never present an abduced hypothesis as a deduced fact.
